# Core resilience implementation

Recorded 2026-10-05. User accepted an internal technical definition of “three-star risk”: extreme inputs, missing/corrupt evidence, AI API failure and stale confirmation must fail safely. This is not a competition rating, certification or bank risk score.

## Accepted product requirements

One core task: prepare before interruption of access to one bank's funds, using current balances and 30-day obligations. Two companions: minimum preparation comparison and a printable one-page plan. English UI, USD; amounts in integer cents. Copilot assists the same task using validated tools. User confirmation must precede applying any proposed allocation.

The implementation must retain Treasury Workspace, Bank Evidence and Scenario Lab. Future receipts, lending, real transfers and broader forecasting remain outside the accepted MVP. Bank evidence is optional for the deterministic calculation, and must never set the unavailable percentage.
